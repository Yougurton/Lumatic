# Ready-made Chroma environments

Made by `scripts/custom-environments.py` from their authors' repositories:

| Collection | Author | Source | Terms |
|---|---|---|---|
| ChaseEnvs | MadChase | https://github.com/MadChase/ChaseEnvs | MIT License, © 2025 MadChase (`licenses/madchase.txt`) |
| BSCEL | Phøenix | https://github.com/Phoenix-BS/BSCEL | MIT License, © 2023 Phoenix (`licenses/bscel.txt`); credit the environments' makers |
| Lonely's Chroma Environments | Lonely (BTS Witch Edit: Fatalution) | https://github.com/LonelyCen/Chroma-Environments | free to use with credit, as its README says (`licenses/lonely.txt`) |

Per environment: `<id>.json` — the environment as a v3 difficulty's custom data and the game's
environment it's built on (Lonely's v2 entries turned into v3 ones: positions × 0.6); `<id>.jpg` — the
author's picture, scaled down. The editor names each environment's author on its card.
