# MadChase's environments

Ready-made Chroma environments by **MadChase**, from https://github.com/MadChase/ChaseEnvs
(MIT License — see LICENSE.txt in this folder, © 2025 MadChase).

What's here, per environment:

- `<name>.json` — the author's `env.dat` (its `customData` for a v3 difficulty and the environment
  it's built on), written without whitespace; the content is unchanged.
- `<name>.jpg` — the author's `PIC.png`, scaled down to a thumbnail.

The notes on which light IDs do what (shown in the editor's Environment window) are the author's,
from each environment's README.
